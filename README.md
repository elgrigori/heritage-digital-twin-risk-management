# Εννοιολογική Μοντελοποίηση Διαχείρισης Κινδύνων και Μηχανισμός Ειδοποιήσεων σε Πολιτιστικά Ψηφιακά Δίδυμα (Heritage Digital Twins)

> Μεταπτυχιακή Διπλωματική Εργασία — Οικονομικό Πανεπιστήμιο Αθηνών (ΟΠΑ)

Το αποθετήριο περιέχει το σύνολο του υλικού υλοποίησης και επαλήθευσης της διπλωματικής: την **οντολογία** διαχείρισης κινδύνων πολιτιστικής κληρονομιάς, τα αρχεία **επαλήθευσης** (λογική συνέπεια + ερωτήματα ικανότητας) και μια **διαδραστική εφαρμογή επίδειξης** (demo) της λειτουργικής ροής παρακολούθησης → αξιολόγησης → ειδοποίησης → απόκρισης.

## Περιγραφή

Η εργασία προτείνει ένα **ενιαίο εννοιολογικό μοντέλο** για τη σημασιολογική αναπαράσταση της διαχείρισης κινδύνων σε μνημεία πολιτιστικής κληρονομιάς, το οποίο υποστηρίζει έναν μηχανισμό υποστήριξης αποφάσεων και αυτόματων ειδοποιήσεων. Το μοντέλο στηρίζεται στη διασύνδεση **τριών καθιερωμένων προτύπων**:

- **CIDOC CRM** — βάση για οντότητες, δραστηριότητες και χρονικότητα
- **CRMdig** — ψηφιακά αντικείμενα και δεδομένα (`D9 Data Object`)
- **RHDTO** (Reactive Heritage Digital Twin Ontology) — ψηφιακά δίδυμα και ψηφιακές λειτουργίες (`HC22 Digital Operation`)

Το μοντέλο εφαρμόζεται σε πέντε μνημεία: **Παρθενώνας**, **Ναός Ποσειδώνα στο Σούνιο**, **Αρχαίο Θέατρο Επιδαύρου**, **Ανάκτορο Κνωσού** και **Μυστράς**.

## Η οντολογία

- **Μορφή:** OWL 2 / Turtle (`.ttl`)
- **Namespace:** `https://w3id.org/heritage-risk-management#`
- **Μέγεθος:** 1.828 τριπλέτες, 268 στιγμιότυπα (individuals)
- **Προσαρμοσμένες κλάσεις:** 16, ορισμένες ως `rdfs:subClassOf` των προτύπων (π.χ. `IncomingMonitoringData ⊑ CRMdig D9`, `RiskEvaluation ⊑ RHDTO HC22`, `RiskAssessment ⊑ CIDOC E13`)

Μπορεί να φορτωθεί σε **Protégé** ή **GraphDB** για εξερεύνηση, συλλογιστική (reasoning) και εκτέλεση ερωτημάτων SPARQL.

## Επαλήθευση

Η ορθότητα του μοντέλου ελέγχθηκε σε **δύο επίπεδα**:

1. **Λογική συνέπεια** — Reasoner **HermiT** (μέσω owlready2). Η οντολογία είναι **συνεπής (consistent)**, χωρίς μη ικανοποιήσιμες κλάσεις (0 unsatisfiable). Βλ. `validation/HermiT_consistency_report.txt`.
2. **Ερωτήματα ικανότητας (Competency Questions)** — 6 ερωτήματα SPARQL που ελέγχουν αν το μοντέλο απαντά στις απαιτήσεις πληροφορίας. Και τα 6 επιστρέφουν μη κενά, ορθά αποτελέσματα (**6/6 PASS**). Βλ. `validation/SPARQL_CQ_results.txt`.

## Διαδραστική επίδειξη (Demo)

Εφαρμογή ιστού σε **React + TypeScript (Vite)** που οπτικοποιεί τη λειτουργική ροή του μηχανισμού και αντιστοιχίζει κάθε βήμα στις κλάσεις της οντολογίας.

### Εκτέλεση τοπικά

```bash
cd demo
npm install
npm run dev
```

Η εφαρμογή θα ανοίξει στο `http://localhost:5173`.
